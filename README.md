# denis.build — static website

A deliberately minimal personal website for Denis Martins. One self-contained HTML file (HTML/CSS/JS), no package install or server required.

## Preview
Open `index.html` in a browser.

## Deploy to Cloudflare Pages
Push `index.html` at the root of a GitHub repo. Connect the repo from Cloudflare Pages. Set the output directory to `.`; no build step is needed. Add a custom domain after the site is working.
